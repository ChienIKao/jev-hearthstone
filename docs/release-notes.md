# Laya 爐石助手 v0.1.0

首個 Windows / MuMu 版本，提供本機 Laya 決策與背景 Android 操作。

## 使用介面

- 深色側邊導覽，集中呈現牌組、局數、裝置連線、開始及停止。
- 狀態與執行紀錄分區，執行時停用重複開始與牌組切換。
- 牌組打法／HSReplay 參考、遊戲預覽／辨識資料、進階控制各自獨立。
- 首次安裝腳本下載卡牌資料與多語模型；雙擊啟動不依賴 PowerShell 腳本執行原則。

## 對局功能

- 標準／開放模式與牌組選擇、連續排位、局數上限及停止。
- 換牌、出牌、英雄能力、攻擊、地標、發現／倒轉選牌及結束回合。
- 以公開局面與合法動作作決策；已知效果用有時限的搜尋，未知效果由 Laya 逐步選擇，執行後重新觀察。
- MuMu ADB 觸控不占用 Windows 滑鼠。

## 安裝

下載 `Laya-Hearthstone-v0.1.0-windows-source.zip`，解壓後先執行 `setup.cmd`，完成後執行 `start.cmd`。需要 Windows、Python 3.12（含 Launcher）、MuMu 及首次下載用網路。本套件不包含 Python、模型、卡牌資料或個人設定；詳細連線與 Android 日誌設定請見 README。
